# Goal Craft Output Template

Use this template when refining a goal into phases and todos.

```markdown
# Goal Craft: <goal>

## Goal
- **Outcome**: <desired state>
- **Verification rule**: <how goal completion is proven>
- **Boundary**: <included/excluded scope>

## Phases
### Phase 1: <phase name>
- **Purpose**: <how this advances the goal>
- **Exit proof**: <how this phase is verified>

Todos:
- [ ] <todo action>
  - **Surface**: <document/system/file/user flow>
  - **Proof**: <test/metric/review/artifact/command>
  - **Depends on**: <dependency or none>

### Phase 2: <phase name>
- **Purpose**: <how this advances the goal>
- **Exit proof**: <proof>

Todos:
- [ ] <todo action with surface and proof>

## Deferred Work
- <work that is related but not required for this goal>

## Risks
- <risk that could change phase order or todo scope>
```
