# Documentation audit output

Scale to the request; a one-claim check needs only a concise finding and evidence.

- Verdict: consistent within scope / repairs needed / unresolved.
- Scope and action: named documents; internal / implementation / combined; audit / check-and-fix.
- Authority: which source proves current behavior, intended behavior, and public promises.
- Claim/scenario map: include only when multiple documents or scenarios need navigation.

| Priority | Claim/location | Evidence/location | Defect owner | Impact | Repair |
| --- | --- | --- | --- | --- | --- |
| P0-P3 or Needs evidence/decision | doc:line | doc/code/contract:line | doc / implementation / unresolved | concrete consequence | update/move/merge/remove/split/resolve |

End with confirmed-correct areas, repair order, unresolved decisions, and actual changes and
verification if any. An audit-only answer states no edits were made. A check-and-fix answer
links changed files and separates remaining issues from fixed ones.
