# Goal Make Output Template

Use this template when defining or evaluating goals.

```markdown
# Goals: <scope>

## Intent
<The original user intent in one sentence.>

## Goals
### Goal 1: <outcome>
- **Type**: product / technical / operational / learning / quality / delivery
- **Boundary**: <what is included and excluded>
- **Verification rule**: <how to prove it is achieved>
- **Evidence source**: <test, metric, review, artifact, command, user signal, trace>
- **Pass criteria**: <clear pass/fail rule>
- **Confidence note**: <why this evidence is credible, or what proxy is being used>

## Not Goals
- <nearby intent intentionally excluded>

## Quantification Opportunities
- <metric, threshold, baseline, sample size, or reason not to quantify>

## Open Questions
- <question that could change the goal or verification rule>
```
