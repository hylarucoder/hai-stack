# README 美化输出模板

用于最终交付美化后的 README 内容和简短摘要。不要把模板当作固定 README 结构，原文结构合理时保留。

```markdown
<完整的美化后 README.md 内容>

---

**美化摘要**

改动了以下几点：
- <结构、标题、列表、代码块、链接或空白修正>
- <another concrete change>

建议后续补充（不在本次改动范围内）：
- <missing content that should be added by project owner, or "无">
```

如果 README 已经规范，使用：

```markdown
README 格式已经比较规范，没有需要强行美化的地方。

**检查摘要**
- <checked area>
- <checked area>
```
