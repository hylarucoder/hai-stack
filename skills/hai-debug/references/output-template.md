# Debugging result

- Result: confirmed cause / likely cause / unresolved; confidence and its limit.
- Symptom: expected versus observed, environment and reproduction conditions.
- Evidence: actual commands/results, logs, code locations, and working/failing comparison.
- Hypotheses: supporting evidence, discriminating checks, and ruled-out explanations.
- Cause: precondition → faulty decision/state → symptom; keep inference labeled.
- Repair: proposed or applied; mitigation versus root fix; affected contract.
- Verification: original failing case and nearby regressions; passed/failed/not run.
- Remaining evidence or next check if blocked.

Scale to the problem. For diagnosis-only requests do not imply code was changed.
